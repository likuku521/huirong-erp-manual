第2章  全局业务规则
以下是从PPT蓝图中提炼的跨模块关键规则：
● 保税物料与非保税物料分开管理，启用批次+仓库核算维度。
● 进口/出口报关业务在关衡关务系统操作，金蝶仅同步基础单据。
● 生产物料先领至车间仓，车间按实际消耗生成领料单（移库模式）。
● 物料档案需维护采购周期、质检周期、生产周期、是否保税、是否质检等属性。
● 拆植业务需指定主产品与联副产品比例；分拣/测试业务启用批次管理。
● 工程变更不支持文档管理；在制品返工需工艺员调整工艺路线。
● 关衡对接的单据审核后不允许反审核或变更。
● 成本核算采用月末加权平均法，按工序核算，在产品材料按完工产量分配。

第3章  原料分拣与测试
3.0  单据链路
核心单据流：采购入库单 → 分拣工单/测试工单 → 分拣入库单(多物料)
3.1  业务适用范围
适用于进口采购废旧内存条、硬盘等多品种混杂原料，统一报关入库后再分拣成不同原料的业务场景；也适用于原料通过测试车间经测试工序转换成其他产品的场景。
3.2  业务规则判断
● 进口采购原料多品种混杂，统一按一种原料报关与采购入库。
● 分拣前必须先完成采购入库，分拣后才存在多种物料。
● 测试后的半成品/产品品种需测试后才能确定。
● 产品启用批次管理，分批核算成本。
● 分拣与测试需分摊制造费用。
3.3  前置准备
● 确认进口采购入库单已完成。
● 明确分拣目标物料编码和批次。
● 准备分拣/测试工单和对应的工艺路线。
● 确认车间仓可用，分拣出的物料需入库到对应仓库。
3.4  详细操作步骤
3.4.1  进口原料采购入库完成后，进入分拣/测试模块新增【分拣/测试工单】。
3.4.2  在工单中选择来源采购入库单，指定分拣前原料编码和批次。
3.4.3  维护分拣/测试产出物料清单，包括各产出物料的编码、批次、数量。
3.4.4  工单审批通过后，执行分拣/测试操作，生成分拣出库（原料消耗）。
3.4.5  分拣/测试完成后，生成分拣入库单/测试入库单，将各产出物料入库。
3.4.6  系统按批次核算分拣/测试产出成本，分摊制造费用。
3.5  审核关注点
● 采购入库单与分拣工单的来源关联是否正确。
● 分拣产出物料清单与实际产出是否一致。
● 制造费用分摊规则是否按配置正确执行。
● 各产出物料入库批次和成本是否正确。

⚠ 风险提示
✘ 分拣前未做采购入库会导致库存不足无法开工单。
✘ 产出物料编码未提前维护会导致无法入库。
✘ 制造费用分摊未配置正确会导致成本失真。

第4章  MRP计划运算
4.0  单据链路
核心单据流：销售订单/预测单 → MRP运算方案 → 计划订单 → 生产工单/采购申请
4.1  业务适用范围
适用于生产计划员根据销售订单和需求预测，通过MRP运算生成生产计划和采购计划的场景。
4.2  业务规则判断
● 物料档案必须维护采购周期、质检周期、生产周期。
● 需有完整的产品BOM（物料清单）。
● MRP计算方案确认后，日常运算无需重新设置方案。
● MRP运算结果生成计划订单，可投放为生产工单或采购申请。
4.3  前置准备
● 确认物料档案已维护完整的提前期参数。
● 确认产品BOM已审核生效。
● 确认当前库存、在途量、在制量数据准确。
● 准备MRP运算方案：计划区间、需求来源、供给参数等。
4.4  详细操作步骤
4.4.1  进入MRP模块，维护【MRP运算方案】，设置计划区间、需求来源、供给参数、展望期等。
4.4.2  执行MRP运算，系统根据销售订单、预测单、BOM、库存等自动计算净需求。
4.4.3  查看MRP运算结果，确认计划订单的正确性。
4.4.4  将计划订单投放为【生产工单】（自制件）或【采购申请】（外购件）。
4.4.5  后续按生产流程或采购流程继续执行。
4.5  审核关注点
● BOM和物料提前期是否准确完整。
● MRP运算是否覆盖了所有需求来源。
● 计划订单投放是否正确区分了自制和外购。
● 库存数据是否在运算前已更新至最新。

4.7  常见风险
⚠ 风险提示
✘ 物料提前期未维护会导致MRP计算的时间窗口错误。
✘ BOM不完整会导致MRP漏算子件需求。
✘ 计划订单漏投放会导致后续生产和采购断链。

第5章  普通生产
5.0  单据链路
核心单据流：生产工单 → 移库领料至车间仓 → 工序汇报 → 生产入库单
5.1  业务适用范围
适用于拆植业务（将原料按固定比例拆分为多种物料）和普通组装业务。拆植BOM需指定主产品与联副产品比例；生产先领料至车间仓，再按实际消耗发料。
5.2  业务规则判断
● 需要创建生产BOM和工艺路线；拆植BOM须指定主产品与联副产品比例。
● 生产工单需区分试产与量产。
● 是否需工序检验通过工艺路线/工序计划控制。
● 先将物料从仓库领至车间仓（移库），车间再按实际消耗生成领料单。
● 工单有两种业务流程：工单状态控制流程和单据转换流程，两者相互关联与合规控制。
5.3  前置准备
● 确认生产BOM和工艺路线已审核生效。
● 确认车间仓已创建并配置。
● 确认生产工单已由计划订单投放或手工创建。
● 准备工序计划、检验标准和车间作业指导。
5.4  详细操作步骤
5.4.1  生产计划员投放或创建【生产工单】，指定生产类型（试产/量产）、BOM、工艺路线、计划数量。
5.4.2  工单审批后，仓库管理员执行【生产领料单】（移库类型），将物料从原料仓移至车间仓。
5.4.3  车间按实际消耗，在车间仓执行【领料单】/【补料单】/【退料单】。
5.4.4  按工艺路线执行各道工序，完成【工序汇报】（含合格数、废品数、工时等）。
5.4.5  若工序需检验，质检员在工序汇报后执行工序检验。
5.4.6  全部工序完成后，执行【生产入库单】将成品/半成品入库。
5.5  审核关注点
● 生产工单类型(试产/量产)是否正确。
● BOM主产品与联副产品比例是否与蓝图一致（拆植场景）。
● 移库领料与实际消耗的差异是否合理。
● 工序汇报数据是否完整，质检是否已执行。
● 保税物料的领料单是否已同步关衡系统。

⚠ 风险提示
✘ BOM中联副产品比例填错会导致产出和成本核算错误。
✘ 移库后车间未按实际消耗做领料单会导致库存不准。
✘ 工序汇报数据不完整会导致成本核算失败。

第6章  生产返工
6.0  单据链路
核心单据流：返工工单 → 返工领料（车间仓） → 返工工序汇报 → 返工入库单
6.1  业务适用范围
适用于在库产品因质量问题需要退回车间返工的业务场景。返工流程与正向生产类似，差异点在于生产用料清单只有产品，需工艺员维护返工耗材，并制定返工工艺路线。
6.2  业务规则判断
● 返工流程类似正向生产流程。
● 返工用料清单中只包含需返工的产品，耗材由工艺员额外维护。
● 需要制定返工专用工艺路线。
6.3  前置准备
● 确认需返工的产品编码、批次和数量已明确。
● 工艺员已维护返工耗材清单和返工工艺路线。
● 确认返工工单已创建并审批。
6.4  详细操作步骤
6.4.1  创建【返工工单】，选择需返工的产品编码、批次和数量。
6.4.2  工艺员在返工工单中维护返工耗材清单。
6.4.3  执行返工领料（从车间仓领用耗材）。
6.4.4  按返工工艺路线执行各道工序并完成工序汇报。
6.4.5  返工完成后执行返工入库单，将修复后的产品入库。
6.5  审核关注点
● 返工耗材清单是否完整。
● 返工工艺路线是否正确。
● 返工入库后的批次和数量是否与原产品对应。
● 返工成本是否单独核算。

第7章  工程变更
7.0  单据链路
核心单据流：ECN申请单 → BOM变更审批 → BOM生效 → 在制品处理
7.1  业务适用范围
适用于BOM生效后调整子项物料单位用量、增减物料、变更替代料等场景。工程变更不支持文档管理；在制品返工需工艺员调整工艺路线。
7.2  业务规则判断
● BOM变更需通过ECN流程审批后才生效。
● 不支持文档管理。
● 在制品需根据变更内容由工艺员决定是否需要返工和调整工艺路线。
7.3  前置准备
● 确认需变更的BOM编号和版本。
● 明确变更内容：增删物料、调整用量、变更替代料。
● 工艺员评估在制品影响范围。
7.4  详细操作步骤
7.4.1  新增【工程变更申请单(ECN)】，选择需变更的BOM并填写变更内容。
7.4.2  提交ECN审批。
7.4.3  审批通过后系统自动更新BOM。
7.4.4  工艺员评估在制品是否需返工，如需要则调整工艺路线或下达返工工单。
7.5  审核关注点
● ECN变更内容是否与实际需求一致。
● 在制品是否已妥善处理。
● 变更后的BOM是否已生效。
● 相关工单是否已按新BOM执行。

第8章  委外管理
8.0  单据链路
核心单据流：委外工单 → 委外采购订单 → 委外发料单 → 委外入库单
8.1  业务适用范围
适用于工单普通委外业务流程。需创建委外BOM、委外工单，通过委外工单关联生成委外采购订单。物料档案需允许委外，并创建委外仓库。
8.2  业务规则判断
● 物料档案需勾选允许委外属性。
● 需创建委外仓库用于委外发料和入库管理。
● 委外工单关联生成委外采购订单。
● 委外发料需从企业仓库发至委外供应商处。
8.3  前置准备
● 确认物料档案已维护委外属性。
● 确认委外仓库已创建。
● 确认委外供应商已维护并可接收委外业务。
● 确认委外BOM已创建。
8.4  详细操作步骤
8.4.1  创建【委外工单】，选择委外物料、委外BOM、委外供应商和数量。
8.4.2  委外工单下推生成【委外采购订单】。
8.4.3  根据委外工单执行【委外发料单】，将物料发至委外仓库。
8.4.4  委外加工完成后，执行【委外入库单】将成品入库。
8.4.5  系统自动核算委外加工费用。
8.5  审核关注点
● 委外工单与委外采购订单关联是否正确。
● 委外发料数量是否与工单一致。
● 委外入库后的库存是否正常更新。
● 委外加工费是否正确结算。

第9章  进口采购
9.0  单据链路
核心单据流：采购申请 → 进口采购订单(关联许可证) → 收料通知 → 采购入库单 → 同步关衡
9.1  业务适用范围
适用于进口采购业务。启用保税控制，物料档案需登记是否保税、是否质检。采购订单明细按物料关联许可证。预付款通过采购关联申请，应付款通过应付单关联申请。报关业务在关衡关务系统操作。
9.2  业务规则判断
● 物料档案须登记进口属性：是否保税、是否质检、海关编码等。
● 采购订单需按物料关联进口许可证。
● 采购入库后数据同步至关衡系统。
● 预付款通过采购关联申请，应付款通过应付单关联申请。
● 报关相关（装箱单、报关单等）在关衡系统操作。
9.3  前置准备
● 确认物料档案已维护进口相关属性。
● 确认进口许可证已办理并在系统中登记。
● 确认关衡系统对接配置已完成。
● 准备报关所需资料。
9.4  详细操作步骤
9.4.1  新增【进口采购订单】，选择进口供应商和物料。
9.4.2  在订单明细中按物料关联进口许可证。
9.4.3  供应商发货后，执行【收料通知】确认收货信息。
9.4.4  货到后执行【采购入库单】（保税物料入库保税仓）。
9.4.5  系统自动将入库数据同步至关衡系统。
9.4.6  预付款通过采购申请关联处理；应付款在应付模块处理。
9.5  审核关注点
● 进口许可证是否已关联到对应采购订单。
● 保税物料是否入库到保税仓库。
● 采购入库后关衡同步是否成功。
● 报关进度是否在关衡系统中正常推进。

第10章  普通采购
10.0  单据链路

10.1  业务适用范围
适用于普通生产物质、耗材等需要出入库管控的采购业务。通过物料档案登记是否需质检。预付款和应付款分别通过采购关联申请。

● 预付款和应付款分别通过采购关联申请。
10.3  前置准备
● 确认物料档案已维护质检属性。

16.0  单据链路
核心单据流：销售订单 → 发货通知 → 销售出库单
16.1  业务适用范围
适用于国内普通销售业务。流程相对标准，不涉及关务对接。
16.2  业务规则判断
● 适用于国内普通销售。
● 标准发货出库流程。
16.3  前置准备
● 确认客户已建档。
● 确认库存充足。
● 确认销售政策和价格。
16.4  详细操作步骤
16.4.1  新增【销售订单】，选择客户和物料、数量、价格。
16.4.2  执行发货通知。
16.4.3  执行销售出库单，扣减库存。
16.5  审核关注点
● 销售订单与发货出库是否一致。
● 库存扣减是否准确。
● 应收是否已创建。

界面：普通销售订单新增页面

说明：标准销售订单截图。

界面：销售出库单页面
字段：出库单编号、来源订单、物料、数量、仓库
说明：体现出库与订单关联。
16.7  常见风险
⚠ 风险提示
✘ 库存不足强行出库会导致后续发货异常。

第17章  销售退货
17.0  单据链路
核心单据流：销售退货申请单 → 销售退货单
17.1  业务适用范围
适用于销售出库后客户退货的场景。通过销售出库单发起退货。出口退货的报关业务在关衡系统操作。
17.2  业务规则判断
● 通过销售出库单发起退货。
● 出口退货报关业务在关衡系统操作。
17.3  前置准备
● 确认需退货的销售出库单。
● 确认退货数量和原因。
● 与客户确认退货。
17.4  详细操作步骤
17.4.1  基于销售出库单新增【销售退货申请单】。
17.4.2  审批通过后生成【销售退货单】。
17.4.3  执行退货入库。
17.5  审核关注点
● 退货单是否关联正确的销售出库单。
● 退货数量是否合理。
● 退货入库后库存是否正确更新。

▎ FIG.17-2  销售退货单页面

字段：退货单编号、来源出库单、物料、数量、仓库
说明：退货入库是培训重点。
17.7  常见风险
⚠ 风险提示
✘ 退货入库仓库选错会导致库存不准。

第18章  成本核算
18.0  单据链路
核心单据流：费用归集 → 费用分配 → 成本计算 → 成本结转
18.1  业务适用范围
适用于月末成本核算。按月末加权平均法，核算维度为批次+仓库。车间费用按自定义比例分摊，车间内按产量或手工指定。在产品材料按完工产量分配。制造费用归集部门包括生产部、仓储、采购、工程设备、质量部。按工序核算成本。
18.2  业务规则判断
● 计价方法：月末加权平均。
● 核算维度：批次+仓库（保税物料分仓库核算）。
● 费用分配：车间按自定义比例，车间内按产量/手工指定。
● 在产品：材料按完工产量分配，工费不参与分摊。
● 制造费用归集部门：生产部、仓储、采购、工程设备、质量部。
● 按工序核算成本。
18.3  前置准备
● 确认所有生产入库、采购入库、销售出库已完成并审核。
● 确认费用数据已完整归集。
● 确认费用分配标准和工序成本配置正确。
● 确认关账期间已设置。
18.4  详细操作步骤
18.4.1  执行费用归集，确认各费用项目已入账。
18.4.2  执行费用分配：车间按自定义比例，车间内按产量或手工指定。
18.4.3  执行成本计算，系统按工序和批次计算各物料成本。
18.4.4  查看成本计算结果，核对异常。
18.4.5  执行成本结转，生成成本凭证。
18.5  审核关注点
● 费用是否已完整归集。
● 费用分配比例是否正确。
● 成本计算结果是否合理（有无异常偏高/偏低）。
● 保税与非保税物料的成本是否分开核算。
● 在产品分配是否正确。

▎ FIG.18-1  费用归集页面
界面：制造费用归集页面
字段：费用项目、费用金额、归属部门
说明：费用归集是成本核算起点。
▎ FIG.18-2  费用分配页面
界面：费用分配标准设置页面
字段：分配维度、分配比例、分配结果
说明：按车间和按产品的分配规则。
▎ FIG.18-3  成本计算结果页面
界面：成本计算单/成本报表页面
字段：物料、批次、本币成本、成本项目
说明：按工序和批次的成本明细。
▎ FIG.18-4  成本结转凭证页面
界面：成本结转凭证生成页面
字段：凭证编号、结转类型、金额、对应科目
说明：成本核算最后一步。
18.7  常见风险
⚠ 风险提示
✘ 费用归集不完整会导致成本偏低。
✘ 费用分配比例错误会导致部门成本失真。
✘ 在产品分配方案不合理会导致完工成本偏差。
✘ 保税和非保税混算会导致关务数据错误。

第19章  关衡关务系统对接
19.0  单据链路
核心单据流：金蝶录入单据 → 审核 → 同步至关衡(暂存) → 关衡确认 → 返回确认结果
19.1  业务适用范围
适用于金蝶云星空与关衡关务系统的数据对接。涉及主数据、采购、生产、销售四个领域的单据同步。单据在关衡确认后不允许金蝶侧反审核或变更。
19.2  业务规则判断
● 主数据：客户、供应商、海关接口对应表，审核后同步。
● 采购：进口订单、采购入库单、采购退料申请单、采购退料单。
● 生产：生产领料单、补料单、退料单（仅保税物料同步）。
● 销售：出口订单、销售出库单、销售退货申请单、销售退货单。
● 同步单据在关衡为暂存状态，确认后返回结果。
● 关衡确认后，金蝶侧不允许反审核或变更。
19.3  前置准备
● 确认关衡系统已部署且网络通畅。
● 确认海关接口对应表已维护。
● 确认需要同步的物料/客户/供应商已维护保税属性。
● 确认关衡用户权限已配置。
19.4  详细操作步骤
19.4.1  在金蝶录入并审核主数据/业务单据。
19.4.2  系统自动将审核后的单据同步至关衡（暂存状态）。
19.4.3  关务人员在关衡系统确认单据。
19.4.4  关衡返回确认结果至金蝶。
19.4.5  关衡确认后，金蝶侧单据不可再反审核或变更。
19.5  审核关注点
● 同步是否成功，是否有失败记录。
● 关衡确认是否已返回。
● 保税物料是否正确识别并同步。
● 同步失败后的重试机制是否有效。
19.6  截图占位与字段要求
▎ FIG.19-1  海关接口对应表
界面：海关接口对应表维护页面
字段：物料编码、海关编码、保税标识、其他映射字段
说明：主数据对接基础。
▎ FIG.19-2  单据同步状态页面
界面：金蝶单据同步状态查看页面
字段：单据编号、同步方向、同步状态、关衡确认结果、同步时间
说明：日常运维最关键截图。
▎ FIG.19-3  关衡确认返回页面
界面：关衡确认结果在金蝶的显示页面
字段：单据编号、确认结果、确认时间、确认人
说明：体现关衡确认后的状态锁定。
19.7  常见风险
⚠ 风险提示
✘ 主数据未同步会导致业务单据同步失败。
✘ 保税判断错误会导致不该同步的单据被同步，或该同步的漏同步。
✘ 关衡确认后金蝶侧仍然反审核会破坏数据一致性。
